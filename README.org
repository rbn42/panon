This is an audio spectrum analyzer for KDE panel.

[[../../wiki/Previews][file:../../wiki/plasmoid/preview.png]] 

** Requirements
|                  | Version          |
|------------------+------------------|
| KDE Plasma       | >= 6.0           |
| OpenGL / GLSL    | >= 3.2 / 1.50    |
** Dependencies

The visual effects are compiled at runtime with =qsb= (Qt Shader Tools).
   
*** Arch Linux
#+BEGIN_SRC sh
sudo pacman -S qt6-websockets qt6-shadertools \
    python-numpy python-pyaudio python-cffi python-websockets 
#+END_SRC

*** openSUSE
#+BEGIN_SRC sh
sudo zypper in qt6-websockets-imports qt6-shadertools \
    python3-numpy python3-PyAudio python3-cffi python3-websockets
#+END_SRC

*** Debian / Ubuntu
#+BEGIN_SRC sh
sudo apt-get install qml6-module-qtwebsockets qt6-shader-baker \
    python3-numpy python3-pyaudio python3-cffi python3-websockets
#+END_SRC

*** Fedora
#+BEGIN_SRC sh
sudo dnf install qt6-qtwebsockets qt6-qtshadertools \
    python3-numpy python3-pyaudio python3-cffi python3-websockets
#+END_SRC

** Installation
*** Via KDE Store

1. Open the "Add Widgets" dialog of your desktop
2. Go to "Get New Widgets" in the bottom
3. Click "Download New Plasma Widgets"
4. Search for "panon"
5. Click "Install"

*** Via Command Line

#+BEGIN_SRC sh
git clone https://github.com/rbn42/panon.git
cd panon

# Download SoundCard and hsluv-glsl
git submodule update --init

# Build translations (optional)
cmake -S translations -B build -DCMAKE_INSTALL_PREFIX="$PWD/plasmoid/contents/locale"
cmake --build build --target install

# To install
kpackagetool6 -t Plasma/Applet --install plasmoid

# To upgrade
kpackagetool6 -t Plasma/Applet --upgrade plasmoid
#+END_SRC

*** Via AUR
[[https://aur.archlinux.org/packages/plasma5-applets-panon/][plasma5-applets-panon]] is available for ArchLinux (Plasma 5 version).
